DATA SAFETY

Settings & Backup

Everything lives in this browser's storage. Back it up before clearing your browser data or switching devices.

💾 Export / Import

Export saves every lesson, revision, test, mistake, target and study-time record as one JSON file. Import restores from that file — it fully replaces current data, so export first if unsure.

🕒 Backfill a historical study day

Bring in a day's numbers from your old timer (e.g. Aug 11–16) so it shows up correctly in Study Analytics. This sets — not adds to — that date's totals.

⚠ Danger zone

This permanently deletes lessons, revisions, tests, mistakes, targets, study-time history and the timer — everything this app has stored in this browser. This cannot be undone. Export a backup first.
